# Ведомость

Готовое приложение для бесплатного статического хостинга. Сборка, сервер,
база данных и вход в ChatGPT для работы не нужны. Все шрифты и генератор
QR-кода включены в файлы приложения; внешних сервисов в приложении нет.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий в своём аккаунте GitHub.
2. Загрузите содержимое этого архива в корень репозитория: index.html должен
   лежать непосредственно в корне, вместе с app.js, model.js, style.css,
   папками fonts и vendor.
3. Откройте Settings → Pages.
4. В Build and deployment выберите Deploy from a branch.
5. Выберите ветку main и папку /(root), затем Save.
6. Дождитесь завершения публикации. Адрес будет показан в Settings → Pages
   рядом с Visit site. Откройте его и нажмите QR-код в приложении.

QR-код создаётся прямо в браузере и использует адрес, по которому открыт
сайт, включая путь репозитория. Никакой замены адреса в коде не требуется.

Официальные инструкции:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Другой хостинг

Те же файлы можно разместить на любом хостинге статических сайтов.
Все ссылки на ресурсы относительные, поэтому поддерживается размещение
как в корне домена, так и в подпапке. Достаточно опубликовать этот каталог;
команда сборки не нужна.

## Данные

Включены пять участников и результаты, перенесённые из журнала и переписки.
Неизвестные оценки отмечены в карточках. Файлы содержат имена и исходные
результаты, поэтому после публикации они доступны посетителям сайта.

Изменения сохраняются в localStorage этого браузера. Общей синхронизации
между посетителями нет. Чтобы перенести свою актуальную ведомость с прежнего
сайта, сначала выберите Данные → Сохранить JSON на прежнем сайте, затем
Данные → Загрузить JSON на новом. Переносить данные между устройствами
можно таким же способом.

## Автономная копия

В разделе Данные можно скачать HTML-файл с текущими данными и шрифтами.
Он работает в браузере компьютера без подключения к интернету.
